## 📋 项目概述

### 背景

**当前痛点**:
1. 用户从银行下载的流水格式各异（工商、招商、支付宝）
2. 发票 XML 文件需要手工处理
3. 发票对账需要人工匹配，容易出错
4. 现有 MCP 工具无法处理原始数据

**解决方案**:
- 创建 `@ssos/mcp-accounting-utils` 工具库（✅ 已完成）
- 创建 `@ssos/mcp-accounting-extended` MCP 服务器（4 个新工具）
- 在 SSOS Web 中集成"导入银行流水"功能（长期）
